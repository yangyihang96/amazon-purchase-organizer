# Prime Pricing

Default comparison for Australia:

- Amazon Australia Prime annual plan: AU$79/year.
- Amazon Australia Prime monthly plan: AU$9.99/month.
- Source checked on 2026-06-03: https://www.aboutamazon.com.au/news/amazon-prime/how-much-is-an-amazon-prime-membership-in-australia

Use `--prime-cost` to override this when:

- the user pays monthly,
- the user has a discounted/student/business plan,
- the account is not Amazon Australia,
- the price has changed,
- or the user wants to compare against an actual charged membership invoice.

Do not infer the user's actual membership cost from the default. Treat the default as a comparison benchmark only.
